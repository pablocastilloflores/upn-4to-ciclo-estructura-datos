# Estructura de Datos - UPN (4to Ciclo)

Repositorio con los laboratorios y proyectos desarrollados durante el curso de Estructura de Datos.

## 📋 Contenido

| Semana | Proyecto | Tecnologías | Descripción |
|--------|----------|-------------|-------------|
| Semana 1 | [MesaTech - Gestión de Tickets](./Semana01-MesaTechGestionTickets) | C#, WinForms | Sistema de gestión de tickets implementado con una lista enlazada como estructura de datos principal |

## 🛠️ Tecnologías generales

- C# / .NET
- Windows Forms
- Estructuras de datos (listas enlazadas, entre otras)

## 📂 Organización del repositorio

Cada semana del curso tiene su propia carpeta, con el proyecto completo y funcional de forma independiente. Para ejecutar cualquiera de ellos:

1. Clona el repositorio
2. Abre el archivo `.sln` correspondiente dentro de la carpeta de la semana en Visual Studio
3. Ejecuta con F5
